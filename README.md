# 🕺 Dancing Fan Man

A groovy web animation featuring a black fan with legs that dances to its own rhythm!

## Features

- **Animated Fan**: Spinning fan blades with body sway
- **Dancing Legs**: Synchronized leg movements
- **Particle Effects**: Groovy particles floating around
- **Interactive Controls**: Play/Pause and Reset buttons
- **Smooth Animation**: 60fps canvas rendering

## How to Run

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Watch the fan man groove!
4. Use the buttons to control the animation

## Files

- `index.html` - Main HTML file with styling
- `dancing-fan.js` - Animation logic and fan man class
- `README.md` - This file

## Customization

Feel free to tweak:
- **Colors**: Change the fan color in `dancing-fan.js`
- **Speed**: Modify the `speed` variable in the animation loop
- **Dance Moves**: Adjust the sin/cos values in `updateAnimation()`
- **Fan Size**: Change `fanRadius` and leg dimensions
